銷售簡報工作室 v2.1（免安裝版）

1. 將 ZIP 完整解壓縮。
2. 雙擊「銷售簡報工作室-v2.1.html」，用 Edge 或 Chrome 開啟。
3. 選取原始 WTD77Report Excel，可一次多選不同週。
4. 等待「匯入成功」，選品類、排除 FA 與分析方式。
5. 按「產生並下載一頁 PPT」。沒有自動下載時，按下方下載連結。

本版本完全在瀏覽器內運算，不需要 BAT、Python、本機服務或網路。
只支援原始 WTD77Report 格式；一般 CSV/Excel 請使用舊版 Python 工具。

分析包括：公司排行表格（最新週前10名）與逐週總淨銷量變化。
合計包含所選品類及通路的全品項，不僅前10名。業績採 Sales；AUV 採報表值並加總。
多週以報表日期排序，每週僅匯入一份；業績差額比較前次匯入週，不保證連續週。
負銷量保留。產品類型取 LV4，沒有推定「門市官網活動」等細分類。
趨勢至少需要兩週。期間與表頭自動讀取，不必手動選品名、銷量欄位。
沒有20MB固定上限，實際可處理量仍受瀏覽器與記憶體限制。

產出的文字、表格與圖表可在 PowerPoint 編輯。版型參考提供截圖，不含品牌Logo。
已以 Chromium 載入完整 HTML 測試實際報表匯入及PPT下載，無網路請求與後端。
測試環境管理政策禁止 file:// 導覽，因此直接雙擊檔案的動作尚未在Windows實測。

內嵌套件：SheetJS xlsx 0.18.5（Apache-2.0）、PptxGenJS 4.0.1（MIT），授權見授權資料夾。

2.1修正：表格垂直對齊使用標準middle值；輸出時確保投影片物件ID不重複。已驗證XML、ZIP、關聯與LibreOffice開檔轉PDF。尚未在Microsoft PowerPoint實測。
