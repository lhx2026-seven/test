## 安裝與開啟

先安裝 Python 3.10 以上版本（Windows 建議使用 python.org 安裝程式並安裝 Python Launcher）。解壓縮整個資料夾後：

- Windows：雙擊 `start-windows.bat`。
- macOS：終端機進入資料夾，執行 `bash start-macos.command`。
- Linux：也可執行 `bash start-macos.command`。

首次啟動需網路下載套件，啟動器每次會確認依賴。系統會開啟本機瀏覽器介面。保持終端機開啟，完成後按 Ctrl+C 關閉。若瀏覽器沒開啟，可在本機開啟 http://127.0.0.1:8765 。連接埠被占用時，可使用虛擬環境 Python 執行 `app.py --port 8766`。

這是需安裝 Python 的可下載原始程式，並非獨立 exe 或 macOS App。

## 報表

以 `sample.csv` 試用。首列為欄名，不可包含合併儲存格或表頭說明；XLSX 讀取第一個工作表，若有合計列請先移除，避免重複計算。CSV 支援 UTF-8 與 CP950。銷量需為非負數，可含千分位逗號；空值與文字會拒絕產生。

同名商品會加總，若不同商品同名，請先以商品編號與品名組成唯一名稱。品類占比需要選擇品類欄位。缺少品類以「未分類」計算。排行最多顯示 8 項；品類顯示前 6 類並合併其餘。總銷量 KPI 顯示至整數，占比顯示一位小數。標題、期間可自行填寫，期間只作標示，不會篩選資料；請先匯出正確當週資料。

PowerPoint 使用原生圖表與文字方塊；可直接改字、移動物件，右鍵圖表「編輯資料」可改數據。KPI 與摘要是產出當下的文字，手動更改圖表資料後不會自動同步。長品名圖表顯示最多 35 字，可在 PPT 手動調整。建議用 Microsoft PowerPoint 開啟；其他簡報軟體可能有字型差異。

支援一次選取多個 Excel/CSV，每份報表代表一週，可在介面編輯週別名稱。請依時間順序選取檔案，建議檔名前加 01、02、03；畫面依此順序比較最後兩週。所有檔案需有相同的品名、銷量欄位名稱。

目前包含單品銷量排行、逐週總銷量變化、品類占比、低銷量觀察。多檔排行與 KPI 會加總所有匯入週；週趨勢顯示各週總銷量與最後兩週增減。低銷量不等於滯銷。只有報表內列出的商品會被分析，未列出的零銷量商品無法推算。

## WTD77Report 專用支援（新版）

可直接匯入原始 WTD77Report Excel，不需刪除表頭或門市欄。程式辨識 ALL 工作表第 3 列欄名，僅採用 All stores 的 QTY；忽略店型、各門市區塊及沒有商品 ID 的合計/空白列，也不讀取 Focus 工作表。日期採第 2 列起訖日期，多份 77Report 會依日期排序。商品以「中文品名 [ID]」辨識，避免同名商品合併；中文缺漏時採英文名稱。

77Report 的負數保留於淨銷量，不推定其原因；其他一般格式仍拒絕負數。商品合計為所有有效 ID 的 QTY 淨額，不使用無 ID 的尾端彙總數字。零銷量項目保留。預設包含 Others，介面可勾選排除該類別；此類別含耗材、費用及其他品項，不能視為純耗材。多份報表需相同涵蓋店數/期間口徑才適合比較，程式不會按店數校正。

真實使用者報表僅用於本機驗證，不包含在下載包或公開儲存庫。


## 公司排行表格（參考第5頁）

在「分析方式」選「公司排行表格（參考第5頁）」。此版型使用原生可編輯 PowerPoint 表格：橘黃標題帶、前10名產品排行與灰底全品項合計。僅支援 WTD77Report，預設品類 King Deal、排除 LV5 = FA exclusive，可在介面更改。公司表格使用專用篩選，不採用其他版型的欄位對應與「排除 Others」選項。

依報表日期取最新一週，依 QTY 降冪排序；同量時依商品 ID 排序。同週 ID 重複或同起始日期匯入多份報表會拒絕產生，避免重算。底部合計為篩選後所有品項，非僅前10名。單價採 PRICE、業績採 Sales（不以單價乘銷量重算），AUV 直接採報表 AUV，合計加總該欄，顯示一位小數。多週匯入時，以前一次匯入週相同篩選的全品項 Sales 比較，增加紅色向上、減少綠色向下；只有一週則不顯示箭頭。比較週不一定相鄰，請確認檔案齊全。產品類型採 LV4：Regular = 常態、Promotion = 活動、LTO = 期間限定；沒有額外推定「門市官網活動」等細分類，可在 PPT 手動改字。

版型依提供截圖重建，不包含品牌 Logo 或原始截圖，也未經實體 PowerPoint 視覺驗證。報表數據與原生表格輸出已通過測試。
