WEEKLY SALES STUDIO

銷售簡報工作室

一次匯入多個 Excel，每份代表一週。選擇單品銷量排行或逐週總銷量變化，產生有排版、可手動編輯的一頁 PowerPoint。

下載 Windows 程式 ZIP

  1. 先安裝 Python 3.10 以上版本，安裝時包含 Python Launcher。
  2. 解壓縮下載的 ZIP，雙擊 start-windows.bat。
  3. 首次啟動會下載套件，完成後會開啟瀏覽器介面。
  4. 選取每週 Excel／CSV，確認週別順序與欄位，產生 PPT。

報表在本機處理，不上傳雲端。這是需要 Python 的本機程式，並非免安裝 EXE。多檔排行加總全部匯入週；週趨勢比較各週總銷量。

已驗證報表處理與 PPT 產生，尚未於實體 Windows 電腦驗證。
